# Button

Text buttons for commands: Add download, Pause all, Clear completed. `primary` (slate) once per view for the main command, usually *Add download*. `accent` (rufous) for a secondary emphasis such as *Resume all*; never next to a primary of equal weight. `secondary` for the rest, `quiet` in dense toolbars, `danger` only to confirm destruction (inside a Dialog). Sentence-case verbs. `size="sm"` in toolbars and rows.
