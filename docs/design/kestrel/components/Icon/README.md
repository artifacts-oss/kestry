# Icon

Outline icons, 1.75 stroke, 24px grid, drawn in currentColor. Use 20px in UI, 16px inside small buttons and labels. Color comes from the parent: `ink` or `ink-muted`; `slate-600` only for an active state. Decorative by default (aria-hidden); pass `label` when the icon is the only content. The full set is `Kestrel.iconNames`.
